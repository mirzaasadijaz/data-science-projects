This repository contains an extensive Exploratory Data Analysis (EDA) of a movie database featuring over 9,000 entries. The project focuses on uncovering trends in genres, popularity, and voting patterns across decades of cinema.

# 🚀 Project Overview
This analysis seeks to answer key questions about the film industry, such as which genres dominate the market, the relationship between release years and movie volume, and identifying the outliers in terms of popularity and fan engagement.

# 📊 Key Features & Analysis
Data Wrangling:

Loading the mymoviedb.csv dataset with specific handling for line terminators.

Cleaning and formatting the Release_Date to extract years for temporal analysis.

Handling large datasets and ensuring data integrity for over 9,000 rows.

Genre Exploration:

Identifying "Drama" as the most frequent genre, accounting for over 14% of the total dataset.

Analyzing genre combinations and their frequency.

Popularity & Voting Insights:

Analyzing "Spider-Man: No Way Home" as a top performer in popularity.

Identifying movies with the highest and lowest engagement rates.

Investigating the 25.5% of the dataset that holds the "popular vote."

Temporal Trends:

Visualizing the volume of movies released per year, identifying 2020 as a peak year for filming in this specific dataset.

# 🛠️ Tools & Libraries
Python 3

Pandas & NumPy: For complex data cleaning and aggregation.

Matplotlib & Seaborn: For creating statistical visualizations such as count plots and distribution charts.

# 📉 Summary of Findings
Most Frequent Genre: Drama.

Highest Voted Genre: Drama (over 18.5% of the high-popularity movies).

Most Popular Movie: Spider-Man: No Way Home (Action, Adventure, Sci-Fi).

Peak Production Year: 2020.
