# New York City Airbnb Data Analysis & Visualization
This repository contains a comprehensive Exploratory Data Analysis (EDA) of a New York City Airbnb dataset. The project involves extensive data cleaning, preprocessing, and the generation of visual insights to understand the dynamics of the short-term rental market in NYC.

# 🚀 Project Overview
The primary goal of this analysis is to explore the pricing trends, room type distributions, and geographical popularity of Airbnb listings. By leveraging Python's data science stack, this notebook transforms raw, messy data into actionable insights.

# 📊 Key Features & Analysis
Data Cleaning & Preprocessing: - Handling significant missing values in columns like host_identity_verified, house_rules, and license.

Type conversion for date columns (last review) and monetary values (price, service fee).

Standardizing categorical data and removing duplicate entries.

Statistical Summary: Descriptive statistics to understand the spread and central tendencies of pricing and availability.

# Data Visualizations:

Price Distribution: A histogram with Kernel Density Estimation (KDE) showing the frequency of different listing prices.

Room Type Analysis: Categorical count plots displaying the dominance of "Private rooms" and "Entire home/apt."

Neighborhood Insights: Visualization of listing counts across different NYC neighborhood groups (Brooklyn, Manhattan, Queens, etc.).

Price vs. Room Type: Box plots illustrating how listing prices vary by the type of accommodation.

Temporal Trends: A time-series analysis showing the growth/frequency of reviews over time.

# 🛠️ Tools & Libraries
Python 3

Pandas: Data manipulation and cleaning.

NumPy: Numerical operations.

Matplotlib & Seaborn: Statistical data visualization.

# 📈 Insights Preview
The dataset contains over 100,000 listings across all major NYC boroughs.

Pricing follows a relatively even distribution across a wide range, indicating a diverse market from budget to luxury stays.

Manhattan and Brooklyn remain the most densely populated areas for Airbnb listings.
